# Resmarkable

Resmarkable provides a clean, object-orientated API wrapper for interacting with the [Resmark Systems](https://www.resmarksystems.com/) reservation system's [REST API](https://helpdesk.resmarksystems.com/en-us/article/resmark-api-getting-started-1r05920/). This gem facilitates retrieving orders, reports, and manifests; creating and managing shopping carts; creating orders; and cancelling orders.

## Installation

Install the gem and add to the application's Gemfile by executing:

```bash
bundle add resmarkable
```

If bundler is not being used to manage dependencies, install the gem by executing:

```bash
gem install resmarkable
```

## Development

After checking out the repo, run `bin/setup` to install dependencies. Then, run `rake test` to run the tests. You can also run `bin/console` for an interactive prompt that will allow you to experiment.

To install this gem onto your local machine, run `bundle exec rake install`. To release a new version, update the version number in `version.rb`, and then run `bundle exec rake release`, which will create a git tag for the version, push git commits and the created tag, and push the `.gem` file to [rubygems.org](https://rubygems.org).
