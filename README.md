# Resmarkable

Resmarkable is a CLI tool designed to retrieve booking manifests and information about single orders from a reservation system API. At this time, it only targets the Resmark Systems reservation system API, but I may generalize it to target other reservation system APIs in the future. Please note that this is an unofficial personal / community maintained project, and is not officially endorsed by or affiliated with Resmark Systems LLC or any other reservation system provider.
